# Components Directory

This directory will hold reusable UI components:
- `map/`: 2D and 3D map viewport components, controls, layers.
- `places/`: Place cards, detail drawers, amenity badges.
- `itinerary/`: Timeline views, day planners, stop cards.
- `ai/`: Assistant chat drawer, prompt suggestions, message bubbles.
- `common/`: Buttons, inputs, modals, tabs, icons.
