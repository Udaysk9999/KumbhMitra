# Services Directory

Centralized data access and external integration layer:
- `api.js`: Base API client using `fetch` or `axios` communicating with backend.
- `placesService.js`: Queries for temples, ghats, medical points, and parking.
- `routingService.js`: Route calculation requests to backend routing endpoint.
- `aiService.js`: Chat prompts and itinerary plan requests to backend AI endpoint.
