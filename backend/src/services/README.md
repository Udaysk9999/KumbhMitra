# Services Directory

This directory is reserved for business logic and external service integrations.

Planned services:
- `gis.service.js`: Spatial queries, radius searches, and geo-fencing.
- `routing.service.js`: Multi-modal route computation and pedestrian routing.
- `ai.service.js`: LLM orchestration for natural language queries and itinerary planning.
- `places.service.js`: CRUD and search operations for places of interest.
