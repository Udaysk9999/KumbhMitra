# Middleware Directory

This directory is reserved for custom Express middleware functions.

Planned middleware:
- `error.middleware.js`: Centralized application error handling and formatted JSON error responses.
- `validation.middleware.js`: Request payload and query parameter schema validation.
- `auth.middleware.js`: Authentication and authorization guards (planned for later phases).
- `rateLimiter.middleware.js`: Request rate limiting for public and AI-intensive endpoints.
