# Models Directory

This directory is reserved for data schemas and ODM models (e.g. Mongoose models for MongoDB) in future phases.

Planned models:
- `Place.js`: Temples, ghats, medical posts, parking lots, dharamshalas, restaurants.
- `Route.js`: Pre-computed emergency paths, procession corridors, and shuttle routes.
- `Event.js`: Shahi Snan dates, Aarti schedules, and religious events.
- `User.js`: User profiles, bookmarks, preferences, and permissions (planned for later).
