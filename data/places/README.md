# Places Data Directory

Stores categorized datasets of verified physical points of interest (POIs) across Nashik and Trimbakeshwar.

### Planned Datasets:
- `temples.json`: Trimbakeshwar Jyotirlinga, Kalaram Temple, Kapaleshwar, Sundarnarayan, Muktidham, etc.
- `ghats.json`: Ramkund, Kushavarta, Laxman Kund, Sita Kund, Gandhi Ghat, etc.
- `hospitals.json`: Civil Hospital Nashik, medical emergency camps, first-aid centers.
- `parking.json`: Designated outer ring parking lots, holding zones, and shuttle terminals.
- `transport.json`: Nashik Road Railway Station, CBS Bus Stand, MSRTC temporary pick-up points.
- `accommodations.json`: Ashrams, dharamshalas, registered pilgrim tents, hotels.
- `facilities.json`: Public washrooms, drinking water points, lost-and-found booths, police chowkis.
